# Recipe Images

This directory contains images for glaze and slip recipes.

## Directory Structure

```
images/
├── flashing_slips/      # Images of flashing slip results
├── woodfire_glazes/     # Images of woodfire glaze results
└── README.md
```

## Image Specifications

- **Format**: JPG or PNG
- **Size**: 800x800 pixels recommended (square aspect ratio)
- **Naming**: Use lowercase with underscores, matching recipe names
- **Examples**:
  - `helmer_flash.jpg`
  - `carbon_trap_shino.jpg`

## Image Requirements

Each recipe references an image file. Add images showing:

1. **Fired result** - The finished glaze/slip on ceramic
2. **Multiple angles** if showing significant variation
3. **Good lighting** to show color and texture accurately

## Adding Images

1. Name the image to match the recipe's `image` field
2. Place in the appropriate subdirectory
3. Use consistent lighting and background for catalog consistency

## Missing Images

Recipes will display placeholder if image is not found.
